🧰 Toolii – Frontend Interface

Toolii is a modern, clean, and responsive frontend interface designed to streamline medical document uploads and management.
This project is built using core HTML, CSS, Bootstrap, and jQuery, following best UI/UX practices and optimized for performance and scalability.

🚀 Project Overview

Toolii provides a professional and user-friendly interface where users can:

Upload and manage their medical documents easily.

View analytics dashboards and reports.

Access responsive layouts optimized for both desktop and mobile.

Interact with clean and modern UI components designed in Figma.

The design layout is based on the provided Figma prototype, implemented using a pixel-perfect approach.

⚙️ Setup Instructions

Clone the repository:

git clone https://github.com/m-sarfraz/project-toolii.git


Open the project folder:

cd toolii-frontend


Run the project:

Simply open index.html in your browser.

Or use a local development server (e.g., VS Code Live Server).

📱 Responsiveness

Mobile: 375px and above

Tablet: 768px and above

Desktop: 1200px and above

All layouts are optimized using Bootstrap’s grid system and media queries.
